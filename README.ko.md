# Youtubook

[English](README.md) · **한국어**

유튜브 영상을 스크롤하며 읽는 **아티클**이나 인쇄용 **그림책**(장면 스크린샷 + 자막 대본)으로 — 전부 브라우저 안에서.

Youtubook은 영상의 장면을 자동으로 나누고, 각 장면을 자막 대본과 짝지어 스크롤형 HTML 아티클(또는 PDF / PPTX 그림책, 대본 TXT)로 내보냅니다. 30분짜리 영상을 다 보지 않고 몇 분 만에 훑거나, 동화책 영상을 부모·교사가 읽어줄 책으로 만들 수 있습니다.

모든 처리는 **100% 브라우저 안에서** — AI 없음, 서버 없음, 영상 다운로드 없음. 유튜브가 이미 제공하는 자막만 사용하고, 영상 스트림을 내려받거나 광고를 차단하거나 콘텐츠를 재호스팅하지 않습니다.

## 기능

- **장면 자동 검출** — HSV 색상 차이 + 적응형(PySceneDetect 방식) 임계값. 민감도 슬라이더로 즉시 재검출.
- **자막에서 내레이션** — 유튜브 자막(수동 우선, 자동 생성 폴백)에서 대본을 뽑아 각 장면에 맞춰 정렬.
- **책으로 보기** — 완성된 책을 다운로드 없이 새 탭에서 바로 열어 읽습니다. 각 장면은 영상의 해당 시점으로 딥링크됩니다.
- **다양한 내보내기 형식** — 또는 저장: 자립형 **HTML 아티클**(각 장면 스크린샷 옆에 자막 대본), PDF(장면당 1페이지), PPTX(발표자 노트에 대본), TXT(대본만).
- **백그라운드 동작** — 추출 중 다른 탭에서 작업해도 되고, 완료되면 알림으로 알려줍니다.
- **한국어·영어 UI** — 브라우저 언어를 따릅니다.

## 동작 방식

1. 유튜브 영상에서 Youtubook 아이콘 클릭 → **그림책 생성**.
2. 영상을 스캔해 장면 경계를 찾고, 장면마다 프레임 한 장을 캡처합니다.
3. 결과 페이지에서 원하는 장면을 고릅니다 — 민감도 슬라이더로 재검출되고, 카드마다 내레이션이 보입니다.

4. **다음** → **형식을 선택하세요**: **책으로 보기**로 새 탭에서 열거나, HTML / PDF / PPTX / TXT로 다운로드.

대본은 선택한 장면들이 영상 전체 타임라인을 나눠 갖습니다 — 각 장면이 "다음 선택 장면 전까지"의 내레이션을 모두 포함하므로, 일부 장면만 골라도 대본이 유실되지 않습니다.

## 설치

**릴리스에서 설치**

1. [Releases](../../releases)에서 `youtubook-v<버전>.zip`을 내려받아 압축을 풉니다.
2. Chrome → `chrome://extensions` → **개발자 모드** 켜기 → **압축해제된 확장 프로그램 로드** → 압축을 푼 폴더(`manifest.json`이 들어 있는 폴더) 선택.

**직접 빌드**

1. `npm install && npm run build` → `dist/` 생성.
2. Chrome → `chrome://extensions` → **개발자 모드** 켜기 → **압축해제된 확장 프로그램 로드** → `dist/` 선택.

요구사항: Chrome 111+

## 사용법

- 추출은 영상이 있는 탭에서 진행되지만, 중간에 **다른 탭에서 작업해도 됩니다** — 완료되면 알림이 옵니다. 단, 그 탭을 닫거나 다른 영상으로 이동하지는 마세요.
- 10분 영상 기준 약 1~3분(회선에 따라 다름).
- 결과 페이지의 민감도 슬라이더로 장면을 더/덜 잘게 나눈 뒤 재검출하세요.

## 개발

```bash
npm install
npm run build   # 타입체크 + dist/ 빌드
npm test        # 단위 테스트 (Vitest)
npm run zip     # 빌드 + 웹스토어 업로드용 zip
```

스택: TypeScript · Vite + @crxjs/vite-plugin · jsPDF · PptxGenJS

## 개인정보

Youtubook은 모든 처리를 브라우저 안에서 로컬로 수행합니다 — 영상 프레임, 자막, 생성된 파일이 기기를 벗어나지 않습니다. [PRIVACY.md](PRIVACY.md) 참고.

## 제한사항

- 자막이 없는 영상은 장면 이미지만 생성됩니다(대본/TXT 없음).
- 라이브/프리미어/DRM 영상은 지원하지 않습니다.
- 유튜브 페이지 구조가 바뀌면 일부 기능(자막 추출 등)이 영향을 받을 수 있습니다.
